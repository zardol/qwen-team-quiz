# Командный интерактивный квиз с ИИ-судьей Qwen

Веб-приложение для проведения командного квиза в реальном времени (рассчитано на 20–24+ одновременных устройств студентов и панель ведущего).

## Основные возможности

- **Две отдельные ссылки**:
  - `/` — страница для студентов (вход по имени, создание или выбор команды, обсуждение идей и отправка ответа капитаном).
  - `/admin` — панель администратора с авторизацией по логину и паролю.
- **Командная механика**:
  - Создатель команды автоматически становится её **капитаном** (`👑`).
  - Участники команды видят вопрос и таймер, предлагают идеи в общий список команды в реальном времени.
  - Капитан может одной кнопкой подставить предложенный вариант в поле ответа, отредактировать и отправить итоговый ответ команды.
- **ИИ-судья Qwen**:
  - Сравнивает ответы всех команд с эталонным ответом, оценивает близость каждого ответа от **0 до 100 баллов**, выбирает самую близкую команду и пишет комментарий судьи.
  - Настроен под **Alibaba Cloud Model Studio / QwenCloud (`ap-southeast-1`)**:
    `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` (модель по умолчанию `qwen-plus`).
  - Если API недоступен или ключ не задан, ведущий может применить резервную алгоритмическую автооценку или выставить/отредактировать баллы вручную.

## Быстрый запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Создайте файл `.env` на основе `.env.example` (необязательно — можно также ввести API-ключ прямо в админ-панели во вкладке **«Настройки ИИ Qwen»**):
   ```env
   PORT=3000
   ADMIN_LOGIN=admin
   ADMIN_PASSWORD=your-strong-password
   ADMIN_SESSION_SECRET=random-secret-string
   QWEN_API_KEY=sk-ваш-ключ-из-qwencloud
   QWEN_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
   QWEN_MODEL=qwen-plus
   ```

3. Запустите сервер:
   ```bash
   npm start
   ```

4. Откройте в браузере:
   - Студентам: `http://localhost:3000/`
   - Администратору: `http://localhost:3000/admin` (логин/пароль по умолчанию: `admin` / `admin123`, если не заданы в `.env`).

## Деплой на Render (через GitHub)

GitHub Pages подходит только для статических сайтов, поэтому серверную часть с WebSocket (`Socket.io`) и секретным `QWEN_API_KEY` лучше всего разместить на **Render**, загрузив этот проект в репозиторий GitHub.

1. Загрузите папку проекта `qwen-team-quiz` в свой репозиторий на GitHub (убедитесь, что файл `.env` не попадает в Git — он добавлен в `.gitignore`).
2. Войдите на [render.com](https://render.com) и нажмите **New + → Web Service** (или **Blueprint**, если используете `render.yaml` напрямую).
3. Подключите ваш GitHub-репозиторий:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Health Check Path**: `/api/health`
4. В разделе **Environment Variables** на Render задайте переменные:
   - `ADMIN_LOGIN` — желаемый логин ведущего (например, `admin`)
   - `ADMIN_PASSWORD` — надёжный пароль ведущего
   - `ADMIN_SESSION_SECRET` — любая длинная случайная строка
   - `QWEN_API_KEY` — ваш API-ключ из `home.qwencloud.com/api-keys?region=ap-southeast-1`
   - `QWEN_BASE_URL` — `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`
   - `QWEN_MODEL` — `qwen-plus`
5. Нажмите **Deploy**. После запуска Render выдаст публичный URL вида `https://your-quiz.onrender.com`:
   - Ссылка для студентов: `https://your-quiz.onrender.com/`
   - Ссылка для админа: `https://your-quiz.onrender.com/admin`

> **Совет перед занятием на бесплатном тарифе Render**:
> Бесплатный инстанс Render засыпает после 15 минут бездействия. За 2–3 минуты до начала квиза откройте `/admin` — сервер проснётся и спокойно выдержит 20–24+ одновременных подключений студентов.
